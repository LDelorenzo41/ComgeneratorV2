Votre page d'accueil : solde, bilan de l'année, derniers travaux et accès rapide aux outils.

## Se repérer

- Le **bandeau du moment** suit le calendrier scolaire : à la rentrée, il propose de créer un scénario ; en période de bulletins, de générer une appréciation.
- **Actions rapides** ouvre directement les outils : **Générer une appréciation**, **Synthèse de bulletin**, **Créer une séance**, **Créer un scénario**, **Écrire aux familles**.

Tous les outils sont aussi dans le menu du haut :

- **Concevoir** : scénarios et séances, et leurs banques ;
- **Évaluer** : appréciations, banque d'appréciations, synthèse de bulletin ;
- **Communiquer** : écrire un message ou répondre à un message reçu ;
- **Ressources** : vos flux d'actualités.

> 💡 Chaque page a sa propre aide : l'onglet **Aide**, sur le bord de l'écran, ouvre le tutoriel de la page où vous êtes.

## Mes crédits

La carte **Mes crédits** affiche votre solde en tokens, avec une équivalence indicative en appréciations et en séances. Les tokens n'expirent pas.

- **Recharger** ouvre la page d'achat de tokens.
- **J'ai un code** permet d'utiliser un code promo (voir la rubrique Code promo).

## Reprendre son travail

- **Reprendre où j'en étais** affiche vos trois derniers contenus enregistrés en banque : appréciations, séances, scénarios. Un clic ouvre la banque correspondante.
- **Mon année avec ProfAssist** compte vos générations depuis le 1er septembre et estime le temps gagné.

Ces cartes n'apparaissent que lorsqu'elles ont quelque chose à montrer. Seuls les contenus enregistrés en banque figurent dans **Reprendre où j'en étais**.

## Actualités

**Actualités pédagogiques** affiche le dernier article de chacun des flux que vous avez choisis sur la page [Ressources](/resources). Sans choix de votre part, elle affiche les dernières actualités du Café pédagogique et d'Éduscol.

Un clic ouvre l'article sur son site d'origine, dans un nouvel onglet. **Tout voir →** ouvre la page Ressources.

## Code promo

1. Cliquez sur **J'ai un code**.
2. Saisissez le code en respectant les majuscules et minuscules.
3. Cliquez sur **Valider le code**.
4. Après « Félicitations ! », cliquez sur **Fermer** : la page se recharge avec votre nouveau solde.

Chaque code ne peut être utilisé qu'une fois par compte. Le même bouton existe dans le menu de l'engrenage, en haut à droite : **J'ai un code !**.

## Questions fréquentes

**Où sont les réglages de mon compte ?**
Cliquez sur l'engrenage en haut à droite, puis sur **Paramètres du compte**. Le même menu propose le **Mode sombre**.

**Le solde reste sur « Chargement… ».**
Rechargez la page. Si le problème persiste, vérifiez votre connexion.

**Mon solde n'a pas changé après un code promo.**
Rechargez la page : les tokens sont bien crédités, seul l'affichage n'est pas à jour.
